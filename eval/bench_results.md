- **Raw claims wrong as returned:** claims in the model's own JSON whose number is not what the text says: `invented` (the quoted number is not in the passage), or `value`, `scale` or `unit` disagreeing with it (for example "18%" typed as USD). Receipts' code re-reads all three from the quoted text and drops invented claims.
  This measures extraction consistency with the input, not factual accuracy of unrestricted model answers.
- **Label errors:** gold claims whose number the model found but labeled with the wrong metric, GAAP/non-GAAP basis or period.
