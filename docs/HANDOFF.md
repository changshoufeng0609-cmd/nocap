# Handoff to Codex (2026-10-27, about 22:00 Taipei)

The product is now **NoCap**, matching Team NoCap (user rename, 2026-10-28); it was originally handed off as Receipts. NoCap is a fact-checker for financial journalists and analysts. Muse Spark extracts every numeric claim from a draft as a typed record. Deterministic code then verifies each claim against SEC EDGAR: XBRL for 10-Q/10-K figures, plus press-release tables from 8-K EX-99. Each claim comes back as ✓ verified, ✗ wrong (with the correct value), ? unverifiable, or ≈ approximate, and every verdict carries its receipt: filing, accession number, acceptance time, and the verbatim cell.

**a. Verifier fixes from J1** (`receipts/verify.py`, `receipts/periods.py`, tests). Each fix needs unit tests.
- **Bounds.** Bound words are authoritative for both direction and tolerance:
  - "more than" / "over" / "exceeding" / "above" / "at least" / "upwards of"
  - "less than" / "under" / "below" / "at most"
  - "nearly" / "almost" (the true value is slightly below)
  - "about" / "approximately" / "roughly" / "around"

  J1 found a false ✓: "more than $4.5 billion" was accepted against Netflix's $4.459B.
