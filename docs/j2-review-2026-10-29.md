## Resolved core findings

| Finding | Reproduction | Required behavior |
|---|---|---|
| J2-1: original bounds can disappear when locating a model quote | Draft: `NVIDIA Q2 FY2027 revenue was under $96.2 billion.` The filed value is $96.221 billion. A complete verbatim span produces `wrong/value_mismatch`. A model quote with an uppercase `Revenue` falls back to `$96.2 billion` alone and produces `verified/match`. An explicitly number-only proposed span also verifies, without a warning. | Preserve relevant modifiers from the source text, or withhold an unsafe extraction. Fixing only the nonverbatim fallback is insufficient because a number-only span is itself verbatim. Avoid copying a modifier from a different figure or sentence. |
| J2-2: canonical level metrics bypass qualification checks | A proposed `net_income` claim for NVIDIA Q2 FY2027 with `$59.688 billion` verifies when its metric text and source span say `net income excluding stock compensation`, `European net income`, or `net income from discontinued operations`, with `segment=None`. Those restrictions cannot be validated by the consolidated net-income fact. | Unsupported qualifications must remain unverifiable. Canonical metric assignment by the model must not erase explicit meaning in its retained metric phrase. Other/percentage paths already include more conservative interpretation checks. |

These are synthetic adversarial model proposals, not evidence of how frequently a live model emits them. The pipeline accepts them, which exposes a deterministic boundary weakness. Local reproduction and full source provenance are retained in `data/eval_runs/j2_core_probe.py` and `j2_core_probe_before.json`. The original evidence file is write-once.

The fixed extractor restores an adjacent bound from the exact original value position, including number-only spans, and distinguishes repeated values with different operators. The fixed verifier checks both canonical metric descriptions and the local source phrase around the value; unsupported qualifications remain `?`, while known period/reporting syntax and legitimate segment labels retain their own receipts. Independent review reran **18 bound + 80 qualifier tests**, including negative controls that prevent another claim's qualifiers from contaminating a valid value.

The original eight probes were replayed unchanged into a separate after file. Both formerly false bound matches now return `wrong/value_mismatch`; all four qualified net-income probes now return `unverifiable/no_evidence`; the valid total and already-correct complete-bound behavior remain unchanged. [Before/after summary and source/evidence hashes](j2-review-probes-2026-10-29.json). This closes the specific reviewed failures; it does not prove that arbitrary model extraction can never mislabel or omit a claim.
